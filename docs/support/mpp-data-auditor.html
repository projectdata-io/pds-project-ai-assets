PDS MPP Data Auditor

Get help checking Microsoft Project (.mpp) data quality, including task and resource relationships, hierarchy, custom fields, progress, calendars, and plan comparisons. This agent does not edit the source files.

Getting started

Open the agent, sign in to PDS, and select an accessible plan. Ask: "Audit this plan for data-quality issues and cite the affected tasks." For a comparison, identify both files and which is the earlier version.

Common issues

  • Cannot open a file: Confirm access using the same account and check that you selected the intended MPP file.
  • Missing custom fields or values: Confirm they exist in the saved plan. A missing value is not necessarily a data-quality defect.
  • Unexpected comparison: Check both file versions and the comparison direction. Review AI-generated findings against the source evidence.
  • Session expired: Select the required files again and repeat the audit.

Contact support

Email support@projectdata.io. Include the agent name, time and time zone, audit question, expected and actual results, affected task or field references, and any displayed error code. Use redacted or synthetic examples.

Do not send passwords, access tokens, private download links, or confidential project files. Agree any necessary sample transfer with support first.
