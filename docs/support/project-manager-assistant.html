PDS MPP Project Manager

Get help using Project Manager to understand delivery status, upcoming work, milestones, dependencies, and risks in a Microsoft Project (.mpp) plan. This agent reads your plan; it does not edit the source file.

Getting started

  1. Open the agent in your Microsoft 365 environment and sign in to PDS when prompted.
  2. Select a project file you are authorized to access.
  3. Ask a specific question, such as: "Summarize delivery status and the next five milestones."

Common issues

  • Agent unavailable: Ask your Microsoft 365 administrator to check app availability and required permissions.
  • File missing or access denied: Confirm you can open the file in its original location using the same account.
  • Missing or unexpected results: Check the selected file, its saved version, and whether the relevant dates or progress values exist. AI-generated analysis should be reviewed against the source plan.
  • Session expired: Select the file again and repeat the question.

Contact support

Email support@projectdata.io. Include the agent name, the approximate time and time zone, steps to reproduce, expected and actual results, and any displayed error code or reference. A redacted screenshot or synthetic example can help.

Do not send passwords, access tokens, private download links, or confidential project files. If a sample is needed, support will agree an appropriate way to share it.
