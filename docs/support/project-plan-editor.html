PDS MPP Plan Editor

Get help applying requested changes to Microsoft Project (.mpp) plans. The agent stages and validates supported edits before committing them. A clear edit request can authorize a write; a second confirmation is not always required.

Getting started

  1. Sign in to PDS and select the intended plan.
  2. Specify the exact tasks or resources, changes, and save destination. Keep a backup or use a copy when evaluating changes.
  3. Review the reported result and open the saved or downloaded plan to verify it.

Common issues

  • Change not supported or validation fails: Read the explanation and correct the request. Not every Microsoft Project field or operation is supported.
  • Cannot save: Check write permissions and the destination. A preview or validated draft is not proof that the file was saved.
  • Conflict or uncertain outcome: Check the destination file and the reported commit result before retrying. Do not repeatedly submit the same edit.
  • Download no longer works: Ask to show the download again while the session is available. If it has expired, reopen a saved copy; unsaved draft recovery is not guaranteed.

Contact support

Email support@projectdata.io. Include the agent name, time and time zone, requested change, save method, expected and actual results, and any displayed error or session reference. State whether a save was reported as successful.

Do not send passwords, access tokens, private download links, or confidential project files. Agree any necessary sample transfer with support first.
