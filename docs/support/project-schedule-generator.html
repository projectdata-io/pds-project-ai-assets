PDS MPP Schedule Generator

Get help creating and updating Microsoft Project (.mpp) schedules from your requirements. The agent validates supported changes before committing the completed plan to the requested destination.

Getting started

Sign in to PDS and describe the project title, start date, tasks, durations, dependencies, and any resources you want included. Specify the output file name and destination. Review assumptions and inspect the resulting plan before using it for delivery decisions.

Common issues

  • Missing information: Supply the required dates, durations, or destination rather than leaving ambiguous requirements.
  • Unexpected schedule dates: Review dependencies, duration units, calendars, and stated assumptions.
  • Validation or save failure: Correct the reported issue and confirm destination permissions. A generated description or preview is not a saved MPP file.
  • Missing download: Ask to show the download again while the session remains available. Save the file promptly; an expired session may require a new generation request.
  • Unsure whether creation succeeded: Check the destination before retrying to avoid duplicate files.

Contact support

Email support@projectdata.io. Include the agent name, time and time zone, a non-confidential summary of the requirements, save method, expected and actual results, and any displayed error or session reference.

Do not send passwords, access tokens, private download links, or confidential project files. Agree any necessary sample transfer with support first.
