PDS Project AI MCP

Get help connecting a compatible AI client to PDS Project AI through the Model Context Protocol (MCP). The service provides tools for working with Microsoft Project (.mpp) files, including reading project data and performing supported, validated edits when authorized.

Getting connected

  1. Use an MCP-compatible client and the PDS connection instructions for that client. Microsoft 365 agents use their configured connection.
  2. Sign in with the intended organizational account and complete any administrator-approved consent requirements.
  3. Open a file you are authorized to access, or provide the required inputs for creating a new plan.

Common issues

  • Sign-in fails or access is denied: Check the account, connection configuration, administrator consent, and file permissions. Reconnect through the client's normal account controls when prompted.
  • No tools available: Confirm the client supports the configured MCP connection and that authentication completed. Include the client name and version when reporting the issue.
  • File cannot be parsed: Confirm it is an MPP file that opens in Microsoft Project, rather than a renamed document or damaged download.
  • Session expired or closed: Open the source file again. Do not assume an unsaved draft can be recovered.
  • Usage limit reached: Check the limit message and the account's plan with your administrator or support. Repeated retries do not remove a limit.
  • Edit validation or save fails: Check supported operations, validation details, and destination permissions. Inspect the destination before retrying a save with an uncertain outcome.

Safe use

Reading a plan does not save edits. Editing workflows can change files when explicitly requested and authorized; validation or preview alone is not a completed save. Verify the reported commit result and saved file. Close sessions when finished, and retain your own saved copies of outputs.

Contact support

Email support@projectdata.io. Include the client name and version, time and time zone, action or tool name, expected and actual results, and any displayed error code or correlation/session reference. Share only redacted request or response excerpts.

Never send passwords, API keys, access or refresh tokens, authorization headers, private download links, or confidential project files. If a sample is needed, support will agree an appropriate way to share it.
